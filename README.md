# Ally Octans

Página estática da comunidade Ally Octans, para GitHub Pages. HTML, CSS e JavaScript, sem banco de dados e sem instalação de dependências.

## Abrir no computador

Abra `index.html` no navegador. Fotos, vídeo e links funcionam localmente. As fontes externas têm fontes alternativas se estiver offline.

## GitHub Pages

No repositório, abra **Settings → Pages → Deploy from a branch**, selecione **main** e **/(root)** e salve. O endereço esperado é `https://rafaellorenzon.github.io/ally-octans/`.

## Atualizar

- Textos e links: `index.html`.
- Cores, aparência e layout de celular: `style.css`.
- Fotos e vídeo: `assets/`. Substitua mantendo os nomes para não precisar editar os caminhos.
- Menu, galeria ampliada e reprodução: `script.js`.

Os três arquivos JPEG e o MP4 vieram da pasta fornecida pelo proprietário. Os originais não foram alterados. O vídeo só inicia por ação do visitante; tem controles nativos, não força som e não baixa o arquivo inteiro antes de o visitante assistir.

Links públicos fornecidos pelo proprietário: Discord, grupo de WhatsApp da guilda e site oficial do Aika Online. A página identifica-se como comunidade independente, não como site oficial do jogo.
